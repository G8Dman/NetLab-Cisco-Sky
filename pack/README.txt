NetLab — Cisco Sky / Minecraft Java 1.21–1.21.1

Установка: положи NetLab-Cisco-Sky-1.21.1.zip в resourcepacks,
затем включи пак в настройках ресурсов и перемести его выше остальных.
На Windows и Linux используется один ZIP. Распаковывать его не нужно.

Солнце — логотип Cisco. Облака состоят из повторяющихся логотипов.
Небо Края также получает узор Cisco. Обычный градиент неба сохранён:
ванильный Minecraft не загружает для него отдельную текстуру неба.
Нужны включённые облака, лучше режим «Быстро», чтобы логотипы были плоскими.
Шейдерпаки могут рисовать собственные солнце и облака: если замена не видна,
выключи шейдеры или их собственное небо/облака.
Дополнительные моды и сам NetLab для работы этого ресурспака не нужны.
Игра при создании не запускалась.
